## 2. Google Play Data Safety Answers
- **Data Collected**:
  - *Approximate Location*: No.
  - *Personal Info*: Optional Name & Email (only if user explicitly creates a cloud profile; otherwise strictly local guest).
  - *Financial Info*: In-app purchase history processed directly by Google Play Billing; no payment card details stored or accessed.
  - *App Activity*: Anonymous gameplay events (levels started, won, failed, boosters used) for progression analytics.
- **Data Sharing**:
  - Data is NOT sold to third parties.
  - Data is NOT shared with third parties except for standard Google infrastructure services (Firebase, AdMob) when enabled by user.
- **Security Practices**:
  - Data in transit is encrypted using HTTPS / TLS.
  - Users can delete their account and all associated cloud data via the in-app "Delete account & data" button.
